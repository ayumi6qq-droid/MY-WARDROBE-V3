# MY WARDROBE V2 | GitHub Pages

## 部署

1. 將 `index.html`、`.nojekyll` 上傳到 GitHub 儲存庫根目錄。
2. 到儲存庫 Settings → Pages → Build and deployment。
3. 選擇 Deploy from a branch，指定 `main` 分支與 `/(root)` 資料夾，儲存。
4. 開啟 GitHub Pages 提供的網址驗收。

此版本是完整單檔，已內嵌 40 組長褲 A/B 共 80 張圖片，以及 5 組短褲實際需要的 17 張去重商品照片，不需要額外上傳 image assets。

**本次修正**：從長褲／短褲切換時，重設查詢為「色系配色」＋「褲子」＋「全部色系」，避免繼承上一模式指定外套／單品的過濾條件。

長褲指定外套會顯示符合的 B 版單張；其他長褲查詢仍維持 A/B。短褲顯示帽子、上衣、短褲、鞋子四件商品，不顯示人偶。

請不要將私人帳號資訊、憑證或無關檔案上傳公開儲存庫。
